# Figure 4 — Functional annotation counts by tool

Total GO, COG, KEGG and EC entries assigned by Prokka, Bakta and Cyan-ote, summed over genomes, one panel per database (2x2), grouped by high- and low-continuity assemblies.

**Inputs:** `data/processed/GOODQ_PBC_Summary.csv`, `BADQ_PBC_Summary.csv`
**Script:** `database_entries.r`
**Output:** `fig04.png`, `fig04.pdf`

## Legend draft

Total GO, COG, KEGG and EC cross-references assigned by Prokka (blue), Bakta (grey) and Cyan-ote (orange), summed over the high-continuity (n = 164) and low-continuity (n = 209) cyanobacterial assemblies. Each panel shows one database. Totals are printed above each bar. The y-axes are scaled separately for each panel.
